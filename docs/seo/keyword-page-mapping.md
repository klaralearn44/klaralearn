# KlaraLearn — Keyword-to-Page Mapping

**Sources:** Moz Keyword Explorer exports for seed clusters `grammar school`, `private tutor`, and `tutor classes`  
**Purpose:** Definitive assignment of every keyword to its owner page before any content or metadata is written. Every keyword has exactly one primary owner. Secondary pages can target the same term but must not compete with the primary owner for the same intent.

---

## Mapping rules applied

| Signal | Rule |
|--------|------|
| Transactional / commercial intent | → Closest matching product or listing page |
| Informational intent | → Blog article that directly answers the question |
| Navigational intent (competitor or platform brand) | → Homepage (brand awareness / comparison layer) |
| Location modifier | → Matching `/location/[city]/` page |
| High volume but low relevancy (rel ≤ 2) | → Secondary/supporting keyword only; not assigned as primary |
| Supply-side intent ("become a tutor", "tutor jobs") | → Excluded (out of scope for parent-facing site) |
| Specific school brand names | → Excluded (not ownable by KlaraLearn) |
